# 🌐 Personal Portfolio - Kavana M A

This is my personal portfolio website showcasing my **skills, projects, achievements, and experience**.  
Built with **HTML, CSS, and JavaScript**, it is fully responsive and designed to reflect my journey as a CSE student and aspiring developer.

---

## 🚀 Features
- **Responsive Design** – Works across devices (desktop, tablet, mobile).
- **Interactive Navbar** – Smooth scrolling navigation with hover effects.
- **Hero Section** – Intro with my name and role.
- **Skills Section** – Categorized skills displayed as badges.
- **Projects Showcase** – Interactive project cards with GitHub & Live links.
- **About Me** – My journey, interests, and activities.
- **Education Section** – Academic history in a clean timeline format.
- **Contact Section** – Links to connect via email and socials.
- **Footer** – Minimal and elegant.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Libraries/Tools:** Google Fonts, Icons  
- **Hosting:** GitHub Pages
